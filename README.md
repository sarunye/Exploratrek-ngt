# ExploraTrek Tours

Bridging Worlds, Beyond Borders! ExploraTrek Tours offers unforgettable adventures in Marsabit County, Kenya.

## Features

- **Adventure Planner:** Interactive tool to calculate group rates and add-on experiences.
- **Tour Packages:** Curated itineraries for Lake Paradise, Chalbi Desert, Loiyangalani, and more.
- **Virtual Travel Companion:** Real-time virtual tours for those who cannot travel physically.
- **Bespoke Experiences:** Custom packages, goat roasting (Nyama Choma), camel rides, and more.

## Pricing

- **Standard Rate:** KES 40,000 per person for the first 3 people.
- **Additional Guests:** KES 2,000 for each additional person (4th+).
- **Self-Transport:** KES 7,000 per person per day (guests providing own transport and food).
- **Add-on Activities:** KES 7,000 per person.

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev:client`
3. Open your browser to the local development URL.

## Tech Stack

- React
- Tailwind CSS
- Wouter (Routing)
- Lucide React (Icons)
- Framer Motion (Animations)
